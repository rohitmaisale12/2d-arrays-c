## Search in Sorted 2D Matrix (O(n+m))

This program searches an element in a row-wise and column-wise
sorted 2D matrix using an optimized approach.

### Approach
- Start from top-right element
- Move left if current element is greater than key
- Move down if current element is smaller than key

### Concepts Used
- 2D arrays
- Loops
- Time complexity optimization

Language: C
